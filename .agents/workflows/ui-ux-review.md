Important : cette phase concerne uniquement la refonte UI/UX de SIKA.

Je veux une amélioration visuelle complète de l'application, mais sans modifier les fonctionnalités existantes.

Contraintes strictes :

- Ne pas modifier la logique métier.
- Ne pas modifier les endpoints API.
- Ne pas modifier le backend.
- Ne pas modifier les providers Riverpod sauf nécessité purement liée à l'affichage.
- Ne pas modifier les modèles métier.
- Ne pas supprimer de fonctionnalités.
- Ne pas changer les flux utilisateur existants.
- Ne pas modifier l'authentification.
- Ne pas modifier la logique Wallet.
- Ne pas modifier la logique SIKA Agent.
- Ne pas modifier la logique KYC.
- Ne pas modifier les appels réseau.

Objectif principal :

Faire une refonte visuelle professionnelle de l'application Flutter SIKA afin d'obtenir une expérience comparable à une application FinTech moderne et premium.

Tu peux :

- Modifier les widgets UI.
- Modifier les layouts.
- Améliorer les espacements.
- Améliorer la hiérarchie visuelle.
- Améliorer les typographies.
- Améliorer les couleurs existantes.
- Créer des composants UI réutilisables.
- Harmoniser les cards.
- Améliorer les boutons.
- Améliorer les champs de formulaire.
- Améliorer les modales.
- Améliorer les animations visuelles.
- Harmoniser le Glassmorphism.
- Réorganiser visuellement les écrans.
- Ajouter des effets visuels légers.
- Améliorer les états loading, empty et error.

Ne commence pas directement une modification massive.

Commence par analyser l'ensemble du dossier :

mobile/lib/

Puis fournis un rapport contenant :

1. Les écrans existants.
2. Les composants UI actuels.
3. Les incohérences visuelles détectées.
4. Les anciens styles encore présents.
5. Les composants qui devraient être mutualisés.
6. Une proposition de Design System pour SIKA.
7. La liste précise des fichiers qui devront être modifiés.
8. Un plan de refonte progressif par phases.

Ensuite, attends ma validation avant de commencer l'implémentation.

Pendant l'implémentation :

- Travaille progressivement.
- Une phase à la fois.
- Ne touche pas aux fonctionnalités métier.
- Vérifie flutter analyze après chaque phase importante.
- Vérifie que flutter test continue de fonctionner.
- Évite les modifications automatiques massives qui pourraient modifier du code non lié à l'UI.

Le résultat final doit être visuellement premium, cohérent et moderne, tout en conservant exactement les fonctionnalités actuelles de SIKA.
