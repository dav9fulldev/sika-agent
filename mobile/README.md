# SIKA Pay — mobile app (Flutter)

See the [main README](../README.md) for the project overview, setup and tests.

```bash
flutter pub get
flutter run --dart-define=SIKA_API_URL=http://<backend-host>:8001   # emulator: http://10.0.2.2:8001
flutter analyze && flutter test
```

English by default; French is available in the app settings.
